1. Clearing a TextBox
It means removing all the text currently inside a TextBox and making it empty.

2. Empty String
An empty string means there is no text or character stored in it. It is used when you want a TextBox to contain nothing.

3. Clear Method
The Clear method is used to remove the contents of a TextBox. After clearing it, the TextBox becomes empty.

4. Putting Text into a TextBox
The Text property is used to place or change text inside a TextBox. For example, it can display a word such as “Hello.”

5. Integer Division
When two values are integers, division gives an integer result. The decimal part is not kept.
For example, 7 divided by 3 gives 2, not 2.333.

6. Double Division
A double data type can store decimal values. When division is performed using double values, the decimal part is preserved.
For example, 7 divided by 3 gives approximately 2.3333.

7. Casting
Casting means changing a value from one data type to another.
In the example, an integer value is changed into a double value so that division can produce a decimal result.

8. ToString
ToString converts a value, such as a number, into text. This is useful when you want to display a value in a TextBox, Label, or MessageBox.

9. MessageBox
A MessageBox is a small pop-up window used to display information, results, warnings, or error messages to the user.

10. Parse
Parse is used to convert text into a number.
For example, a number entered by the user in a TextBox is initially treated as text. Parsing converts that text into a numeric value so the program can calculate with it.

11. Average
Average means the total of several values divided by the number of values.
For three test scores:
Average = (Test 1 + Test 2 + Test 3) ÷ 3

12. n1 Number Format
The n1 format displays a number with one digit after the decimal point.
For example:
80 → 80.0
83.666 → 83.7

13. Try
Try is used to contain code that might produce an error. The program attempts to execute that code.

14. Catch
Catch handles an error if one occurs inside the try section. It can display an error message to the user instead of allowing the program to stop unexpectedly.

15. Exception
An exception is an error that happens while the program is running.
For example, trying to convert non-numeric text into a number can cause an exception.

16. Clear Button
A Clear button removes the values entered by the user and also removes the displayed result. It returns the input areas to an empty state.

17. Exit Button
An Exit button closes the current form or application window.
